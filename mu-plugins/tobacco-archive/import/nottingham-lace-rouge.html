Description

The first tobacco in the "Nottingham Lace" series, each tobacco is a VaPer (Virginia & perique) with a different base Virginia/cavendish. For the Rouge a fruity red Virginia is used, which has a light alcohol topping. Added to that is some deep rich and smoky Kentucky, this keeps the blend cool and slow burning. To give a little spice and some zing, perique is added (16%). A fruity and spicy tobacco, with plenty of depth in not only flavour, but body.
